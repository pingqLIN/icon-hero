## 為什麼使用 Icon Hero

Icon Hero 是一個可以直接在線上使用的圖示轉換工具。你不需要安裝桌面軟體，也不需要把素材交給雲端服務處理；只要開啟網站，就能把設計稿、Logo、截圖或 favicon 轉成常用圖示格式。

- **即開即用**：進入線上網站即可開始轉換，適合臨時整理專案圖示或快速交付素材。
- **多格式一次完成**：同時輸出 PNG、ICO、ICNS，覆蓋網站、Windows、macOS 與一般專案需求。
- **多種輸入方式**：支援本機圖片、拖曳、剪貼簿貼上，以及 HTTPS 網址擷取。
- **批次下載**：多個圖示可以一次打包，減少重複下載與整理時間。
- **本機隱私**：轉換在瀏覽器內完成，圖片不會離開你的裝置。
- **最重要的是**：因為很可愛。

## 三步驟完成圖示轉換

### 1. 加入圖片

點選上傳、拖曳圖片到頁面、貼上剪貼簿圖片，或輸入 HTTPS 網站網址。Icon Hero 會自動分析可用素材。

<p align="center">
  <img src="docs/images/step-add-image.gif" width="760" alt="Add image by drag and drop in Icon Hero">
</p>

### 2. 等待即時轉換

工作區會顯示每個項目的處理狀態，完成後可直接取得 PNG、ICO、ICNS。

<p align="center">
  <img src="docs/images/step-auto-convert.gif" width="760" alt="Icon Hero automatically converts images to icon formats">
</p>

### 3. 下載或套用

下載單一格式、批次打包 ZIP，或依平台產生可複製與下載的本機腳本，用來快速套用資料夾或應用程式圖示。

<p align="center">
  <img src="docs/images/step-download-apply.gif" width="760" alt="Download converted icons from Icon Hero">
</p>

## 支援內容

| 類型 | 支援 |
|------|------|
| 輸入 | PNG、JPG、ICO、ICNS、剪貼簿圖片、HTTPS URL |
| 輸出 | PNG、ICO、ICNS、ZIP 批次包 |
| 線上使用 | Chrome、Edge、Firefox、Safari |
| 進階套用 | Windows PowerShell、macOS shell/osascript、Linux shell |

> 拖曳已轉換圖示到檔案總管的體驗，建議使用 Chrome 或 Edge。
